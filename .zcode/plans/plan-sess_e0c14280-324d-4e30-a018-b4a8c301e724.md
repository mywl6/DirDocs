# DirDocs 后台「文档管理」改造方案（v1.7.0）

把现在的「能应急用」升级成「好用、能高频用」：类 Typecho 的文档编辑 + 分类（目录）管理。核心思路是**不新增依赖、不改安全边界、服务端渲染兜底 + 前端渐进增强**，严格遵守现有产品哲学（安全 > 部署方便 > 使用方便，只做搜索/设置/编辑/上传四件事的克制原则）。

---

## 一、现状痛点（实测代码得出）

| 痛点 | 现状 |
|---|---|
| 新建文档 | 单一文本框手填 `目录/文件名.md`，无目录选择、无模板、无默认标题 |
| 无目录管理 | 后台完全不能建目录/重命名目录/删目录，只能 FTP；新建时父目录不存在就直接报错（md_admin.php:923 明说"ftp/资源管理器里建好再来"） |
| 编辑器 | 裸 textarea，无工具栏、无 Tab 缩进、无 Ctrl+S、无离开拦截、无字数统计、无 front-matter 辅助 |
| 列表 | 平铺全站路径一张表，无目录分组、无标题列、无搜索过滤、无最近 N 篇快速入口 |
| 交互 | 全部整页 POST + 302，保存/删除都要等整页刷新；删除确认是原生 `confirm()` |
| 移动/改名 | 借「重命名」改全路径，要手打目标目录 |
| 无快速操作 | 无「复制文档」「查看前台」「插入 front-matter」 |

## 二、设计原则（先过产品哲学筛子）

1. **分类管理 = 目录管理**，不引入数据库/分类实体。文件树即分类——这正是 SPEC 1.4「文件即内容，所见即所得」的延伸，零配置不破坏。
2. **编辑器仍是 textarea**（零依赖、PHP 7.1 兼容、CSP 无 unsafe-inline 全守住），增强全部来自 admin.js 渐进增强 + textarea 原生 API。
3. **服务端永远兜底**：所有 AJAX 动作都有等价的可访问表单路径；JS 挂掉时功能完整可用。
4. **安全边界零变化**：`md_resolve_path_only` / `md_resolve` / `md_safe_name` / 白名单 / CSRF / `data-confirm` 全部沿用，新动作一律过同一套校验；新增的建目录只调已存在的 `md_safe_dirname`，拒绝与已有文件/目录重名。
5. **不做**：拖拽排序（会改文件名，破坏 order 语义）、回收站（本地文件即真相）、Markdown 编辑器库（CDN 依赖）、分屏实时预览（成本高收益低，列入后续可选）。

## 三、功能设计

### 3.1 文档管理页（do=docs）重做
- **树形目录 + 文档列表**：复用前台 `md_children()` 的排序逻辑（数字序+名称），目录在前文档在后；目录可折叠（`<details>` 与前台导航同语言），默认展开有文档的目录。每行显示**标题**（front-matter title 或 H1，已由 `md_scan_head_meta` 采集，现成数据）+ 路径 + 相对修改时间。
- **顶部工具条**：搜索框（前端实时过滤路径/标题，纯 DOM 过滤不发请求）+ 「新建文档」+「新建目录」。
- **行内操作**：编辑 / 重命名·移动 / 复制 / 删除（保留 POST+confirm），新增「查看」前台链接。
- **每目录行尾**：「在此新建」按钮 → 带 `dir=` 预填进编辑器。
- 空站点引导文案保留并强化。

### 3.2 新建目录 / 重命名目录 / 删除目录（新增 do 分支）
- `do=dirnew`：表单只填「目录名」（单段，`md_safe_dirname`）+「父目录」（下拉，列全站目录，含根）。禁止与现有文件/目录重名；空目录删除直接 `rmdir`。
- `do=dirrename`：旧路径 readonly + 新父目录下拉 + 新目录名。**移动整个目录**（含内部全部文档）——这是现在完全缺失的能力，`rename()` 原生支持。
- `do=dirdel`：只允许删空目录（`rmdir` 失败即提示"目录非空"），非递归删除——防止误删整棵子树，符合安全优先。
- 目录操作后同样 `md_tree_cache_clear()`。

### 3.3 编辑器升级（do=new / do=edit）
- **标题字段**（可选）：填了就在保存时自动生成/更新 front-matter `title:`；留空则不动现有 front-matter。保存时若文件无 front-matter 但填了标题，自动补 `---\ntitle: xxx\n---\n` 头。
- **目录下拉 + 文件名输入**取代手打全路径：目录下拉列全站目录（含"根目录"），文件名输入框只填 basename，实时拼接预览完整路径。老手仍可直接在预览里改全路径（预览框可编辑，失焦回填两字段——双向同步）。
- **工具栏**（admin.js 实现，纯 textarea 包裹语法）：粗体/斜体/删除线/行内代码/标题(循环 H1→H2→H3)/无序列表/有序列表/任务列表/引用/链接/图片/表格/代码块/分隔线。支持选中文本包裹、无选中插入占位符并选中；所有操作用 `document.execCommand('insertText')` 兼容路径 + 现代 `setRangeText`，保证撤销栈可用。
- **键盘**：Ctrl/Cmd+S 保存（preventDefault 后提交表单）、Tab/Shift+Tab 缩进与反缩进（多行批量）、Ctrl/Cmd+B / I 快捷键、离开页面前 `beforeunload` 拦截（仅在有改动时）。
- **状态栏**：字数 / 字符数 / 行数 / 光标行列 / 保存状态提示。
- **AJAX 保存**（渐进增强）：fetch POST 到同一 `do=edit` 动作，请求体带 `_token` + `ajax=1`，服务端识别后返回 JSON `{ok:true, ...}` 而非 302；成功后 toast「已保存」+ 状态栏更新 + 顶部标题栏的未保存圆点消失。**服务端同时保留完整 PRG 路径**（无 JS 时表单照常 302 回 `?saved=1`）。AJAX 响应同样过 CSRF/校验，错误以 JSON 返回并在表单顶部渲染 alert。
- **底部操作行**：保存 / 保存并查看 / 返回列表 / 删除此文档。
- 保留 front-matter 未闭合拦截与白名单校验，错误信息不变。

### 3.4 重命名·移动合并页（do=rename 升级）
- 新路径输入改为「目录下拉 + 文件名」双字段，与编辑器同款；目标目录可搜索/可打。
- 增加「目标路径预览」，与现有查重/父目录校验复用。

### 3.5 复制文档（do=copy，新增）
- 从任意文档一键复制为新文档：默认名 `原名 副本.md`，用现成的 `md_unique_name()` 防冲突，复制后跳编辑器。

### 3.6 UI 组件（admin.css 新增）
- 目录树样式（`<details>/<summary>` 折叠、缩进导线、目录/文档图标、hover 出行内操作）。
- 工具条（`.admin-toolbar`）、徽标（首页/NEW 标签复用前台 `md_tree_tag_html` 思路）。
- Toast（右下角，复用 token + `--shadow`，3 秒自动消失）。
- 自定义确认弹窗（替代原生 confirm，Bootstrap Modal 已在 bundle 里；保留 `data-confirm` 语义，admin.js 接管为弹窗，无 JS 时降级原生 confirm——实现方式是先 `confirm()` 语义保留在 submit 拦截里，JS 增强只换皮）。
- 编辑器工具条/状态栏样式，textarea 保持 `.admin-editor`。

## 四、后端改动清单（_dir/lib/md_admin.php）

| 位置 | 改动 |
|---|---|
| `md_admin_dispatch` switch | 新增 case：`dirnew` `dirrename` `dirdel` `copy`；`edit` 分支识别 `ajax=1` 返回 JSON |
| 新函数 `md_admin_docs` 重写 | 树形渲染 + 搜索过滤参数 + 标题列 + 行内查看/复制 |
| 新函数 `md_admin_dir_new/rename/del` | 单段目录名校验（`md_safe_dirname`）+ 父目录下拉数据 + 重名/非空检查 + `mkdir/rename/rmdir` + 清缓存 |
| 新函数 `md_admin_doc_copy` | `md_unique_name` + 复制 + 跳编辑器 |
| `md_admin_doc_edit` | 增加 title 字段处理（front-matter 合并/生成）、目录+文件名双字段提交归一化成 `f`、AJAX JSON 分支 |
| `md_admin_doc_rename` | 表单换双字段，校验逻辑不变 |
| `md_admin_editor_form` | 重写：标题字段、目录下拉、文件名、路径预览、工具栏、状态栏 |
| `md_admin_dir_options($tree,$sel)` | 新 helper：生成全站目录 `<option>` 列表（树形缩进 `—` 前缀） |
| `md_admin_title_save($content,$title)` | 新 helper：front-matter 合并（解析现 FM→改 title→重组；无 FM 且 title 非空则生成） |
| `md_admin_ico` | 补图标：folder-plus / folder / arrows-move / files / eye / search / save / bold 等（Bootstrap Icons 已加载，零成本） |

**约束遵守**：PHP 7.1 语法（无箭头函数/无 str_starts_with/nullsafe 等）；所有新 POST 过 `md_csrf_guard()`；路径一律 `md_resolve_path_only` 起步；错误信息不泄露绝对路径；目录操作拒绝 `_dir` 段与保留名。

## 五、前端改动清单

- `_dir/assets/admin.js`（82→约 420 行）：保留现有 3 个行为，新增 5 个模块，仍 IIFE + 事件委托 + 分功能 try/catch：
  1. `mdToolbar`：工具栏按钮包裹文本、Ctrl+S/B/I、Tab 缩进
  2. `mdSave`：AJAX 保存（fetch + FormData，`ajax=1`），toast、未保存标记、beforeunload
  3. `mdToast`：右下角提示（新建 DOM，复用 token）
  4. `mdConfirm`：`data-confirm` 弹窗化（Bootstrap Modal；无 Bootstrap 时降级原生 confirm）
  5. `mdTreeFilter`：文档列表搜索过滤 + 目录默认展开逻辑
  6. 路径预览 ↔ （目录+文件名）双向同步
- `_dir/assets/admin.css`（149→约 330 行）：目录树、工具条、toast、modal 皮肤、编辑器工具条/状态栏、路径预览条。
- **零内联脚本**不变（CSP `script-src 'self'` 不放开）；`admin.js` 已在 asset 白名单，无新文件、无白名单改动。

## 六、明确不做（写进文档备查）

- 拖拽排序 / 可视排序（会改文件名，违背 order 语义）
- 回收站 / 版本历史 / diff（本地文件即真相，与 Git/FTP 分工）
- Markdown 编辑器库、分屏实时预览、图片粘贴上传（后续可选）
- 多用户 / 权限分级
- 自定义分类实体 / 标签系统

## 七、兼容与升级

- 旧 URL 全部有效：`?a=admin&do=edit&f=xxx` 语义不变（新字段缺省即旧行为）。
- 升级仍只覆盖 `_dir/lib/` 与 `_dir/assets/`，`index.php`、config、cache、themes 不动——本次**不需要改 index.php**（新 do 分支全在 md_admin 内部）。
- `MD_VERSION` → `1.7.0`；在 `MD-Docs开发文档.md` 追加 v1.7.0 变更记录（含"分类管理=目录管理"的哲学裁决说明）。

## 八、验证

1. `php -l` 四个 lib 文件 + 7.1 兼容自查（无 8.0 函数）。
2. `php -S 127.0.0.1:8123` + curl 走查：登录 → 文档列表（树形）→ 新建文档（选目录+标题+模板）→ AJAX 保存（验证 JSON 分支与 PRG 兜底）→ 重命名到别的目录 → 复制 → 删除 → 新建目录 → 目录改名（连带移动内部文档）→ 删空目录 → 删非空目录（应拒绝）。
3. 浏览器实测：工具栏各按钮、Ctrl+S、Tab 缩进、离开拦截、toast、确认弹窗、搜索过滤、深浅主题下样式。
4. 前台回归：编辑后搜索能立即命中（mtime 失效链路未被破坏）。
5. 缓存/只读模式：`read_only=true` 时所有写按钮置灰并提示。

## 九、落地顺序（建议 4 步，每步可独立验证）

1. **后端先行**：目录 CRUD + copy + dispatch 分支 + helper 函数（纯服务端，列表页同步换成树形）。
2. **编辑器后端**：title 字段、目录+文件名双字段、AJAX JSON 分支、表单重绘。
3. **前端增强**：admin.js 六模块 + admin.css 新组件。
4. **收尾**：SPEC 文档 v1.7.0 记录、版本号 bump、全量回归。
