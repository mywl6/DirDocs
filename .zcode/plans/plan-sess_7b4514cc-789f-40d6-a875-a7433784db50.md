# DirDocs i18n（v1.10.0）：中文 + 英文全站覆盖

## 已确认的决策
- **范围**：前台（~120 条）+ 后台（~330 条）一次做完；JS 文案（~36 条）一并处理
- **语言机制**：新增配置 `language`（`auto` / `zh-CN` / `en`），`auto` 按 Accept-Language 含 `zh` 判定（复用 `md_cdn_active` 的既有先例）；无访客切换按钮、无 URL 语言前缀、不翻译文档内容（只翻 UI chrome）
- **零依赖**：不用 gettext/.po，语言包就是纯 PHP 数组文件（与 config.php/theme.php 同模式）

## 架构

### 1. 新模块 `_dir/lib/md_i18n.php` + 语言包 `_dir/lib/lang/`
```
_dir/lib/md_i18n.php        解析当前语言 + md_t() 助手 + JS 词典导出（~120 行）
_dir/lib/lang/zh-CN.php     全部现有中文文案（~450 key，纯数据 return array）
_dir/lib/lang/en.php        同键英文翻译（复数处用 array('one'=>..,'other'=>..)）
```
- `md_lang_current()`：读 `language` 配置，`auto` 时 Accept-Language 含 zh → `zh-CN` 否则 `en`；请求内 static 缓存
- `md_t($key, $vars = array())`：取词 → 查不到回落 zh-CN 包 → 再回落 key 本身；`{name}` 占位符 strtr 替换；值是数组时按 `$vars['n'] == 1` 取 `one`/`other`（英文复数，如 "Found 1 document" / "Found {n} documents"）
- `md_i18n_js_attr()`：把 JS 侧需要的固定键子集 json_encode 后放进 `data-md-i18n` HTML 属性（md_e 转义；CSP 不变、无内联脚本）
- `index.php` 的 `$md_libs` 数组加入 `md_i18n.php`（头注释"四个模块"同步改"五个"）

### 2. 前台 PHP 改造
- **md_pages.php**（~60 条）：`本页大纲/首页/刚刚/N小时前/约N分钟阅读/反馈胶囊/搜索页/最近更新/翻页` 等全部换 `md_t()`；相对时间用 `{n}` 占位
- **md_engine.php**：`md_abort` 的 404/403 页文案与 lang 属性 → `md_t()`；`md_config_defaults()` 增加 `'language' => 'auto'`，`md_config_load()` 加白名单归一化（非法值回落 auto）
- **md_theme.php**：`md_page_fallback` 2 条 + lang 属性；`md_page` 上下文新增 `$lang` 变量；主题包规范注释的 helper 清单追加 `md_t`
- **themes/default/view.php + ocean/view.php**：`lang="zh-CN"` → `lang="<?php echo $lang; ?>"`；`<html>` 输出 `data-md-i18n` 属性；~26 条文案 → `md_t()`（模板直接调用全局函数，契约向后兼容——旧自定义模板不调用 md_t 就维持原样中文）
- **md_admin.php 的 `md_risk_html`**（前台所有页面可见的安全警示 3 段）→ `md_t()`
- `index.php:65` 启动错误信息保持原样（lib 加载期 i18n 尚未就绪）

### 3. 后台改造（md_admin.php ~330 条 + admin.js ~20 条）
- 全部硬编码中文 → `md_t()`，按函数区块推进（概览/文档/编辑器/目录/附件/缓存/设置/登录/首设引导/错误信息）
- `md_admin_html_head` 的 `<html>` 输出 `data-md-i18n` 与动态 lang
- **admin.js / builtin.js**：IIFE 顶部加 `mdT(key, fallback)` 助手（从 `data-md-i18n` 读 JSON；属性缺失时用原中文兜底，兼容用户自改的旧模板）→ 逐处替换硬编码字符串

### 4. 语言耦合的业务逻辑（功能性，非文案）
- `md_is_dir_index_name` / `md_home_doc_rel` / 树标签 stem 名单：目录索引候选文件名**无条件增加** `home`（英文站惯例，纯增量）
- 树标签显示「首页」→ `md_t('home')`

### 5. 明确不做（出范围）
- 主题包显示名（「默认主题」「Wiki（青绿）」）保持原样——那是播种出来的用户数据文件
- `site_title` 默认值「我的文档」保持——属站长数据而非 UI 文案
- sitemap / canonical / hreflang 不动（无 UI 文案）；树缓存 / 搜索索引存的是文件数据，与语言无关，不动指纹
- CSP 完全不变（README 安全章节措辞红线不受影响）

### 6. 后台设置页
设置页新增「界面语言」下拉：`自动（跟随浏览器）/ 简体中文 / English`，读写走现有 config 保存通道。

### 7. 版本与文档
- `MD_VERSION` 1.9.0 → **1.10.0**（顺带刷 JS 资产长缓存与树指纹）
- `index.php` 头注释、`MD-Docs开发文档.md`（主题包规范 helper 列表 + 新增 i18n 章节）、README 功能简介提一句中英双语

### 8. 验证
- `php -l` 全部改动文件
- `php -S` 起服务，curl 验证首页/搜索/404/403/sitemap/admin 登录页：分别带 `Accept-Language: en` 与 `zh-CN`，核对 html lang、data-md-i18n JSON、文案切换
- 后台设置页切换 language 三态各验一次；确认 JS 侧 mdT 兜底生效

### 实施顺序
1. md_i18n 模块 + 两个语言包骨架 + index.php 挂载 + 配置项与归一化
2. 前台 PHP（md_pages → abort/fallback → 模板 → risk_html）
3. builtin.js
4. 后台 md_admin.php（分区块）+ admin.js
5. 设置页语言下拉
6. 版本号 + 文档
7. 全量双语验证
